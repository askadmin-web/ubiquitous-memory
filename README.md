# Cathy Rudolph — Portfolio Site
Interactive portfolio for an Implementation Manager with 16 years of 
full-lifecycle delivery experience across B2B SaaS and low-code platforms.

**Live site:** https://askadmin-web.github.io/ubiquitous-memory/

Pages:

- Welcome — landing page, links to all eight pieces

Credentials & Evidence

- Resume — interactive skills with expandable evidence, full work history, certifications
- Global Reach — onsite implementations across 4 regions, 14 countries, 16 cities

Delivery Practice

- Implementation Framework — how I run implementations, two delivery shapes, six-phase framework, 8-week timeline
- The Same Picture, Five Thousand Pieces — five delivery variables under two institutional conditions, concentrated functions versus separated ones; what changes most is not delivery, it is discovery
- What Breaks When Delivery Scales — five mechanisms that work at six concurrent implementations and stop working at forty, the point each one fails, what replaces it, what the replacement costs
- Same Stage, Different Room — two post-sales role-play setups that look identical on a calendar invite, one with a client across the table, one with colleagues; what can be asked in each room and what it costs to confuse them

How It Was Built

- Resume Process with AI — manual vs. AI-assisted job search workflow, nine steps, every decision point documented
- Job Description–Resume Comparison Interactive — fictional JD, fictional candidate; MegaHandy's Illuma Engineer role mapped against Joseph Swan's resume, demonstrating the click-to-map interaction on its own terms, apart from any real application
