How It Was Built: Resume Process with AI
Discovering judicious addition of AI-enabled workflow and value-added delivery framework.
The job search process — manual vs. AI-assisted
Manual Process
Nine steps. Time-intensive at every stage.
AI-Assisted Process
Same steps. Different cost at each one.

Tools
A Visualping — cloud-based careers page monitor, 3-hour check intervals
B Job boards — LinkedIn, DailyRemote, Teal, Remote Rocketship, Jobright, ZipRecruiter
C Claude — triage, resume build, cover letter, outreach drafting
D Perplexity — research and verification (outputs treated as drafts requiring accuracy check)
E WorkLog — FileMaker-based application tracking database
Where human judgment is still required
AI accelerates. It does not decide. Triage flags traps and filters noise — but the tier boundary call is human. The build brief is approved in writing before any file is touched. Cover letter voice is reviewed and rewritten when the style doesn't hold. AI can make mistakes; the prime directives exist because it has. The hybrid works because the decision points are explicit, not assumed.
